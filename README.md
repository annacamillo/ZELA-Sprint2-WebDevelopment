# ZELA — Sprint 2 | Web Development

## Sobre o ZELA

O ZELA é um projeto que estamos desenvolvendo na FIAP, pensando em como a tecnologia pode ajudar a população a se preparar e agir em situações de risco, como enchentes, alagamentos e deslizamentos.

Nesta Sprint, nosso objetivo foi criar duas páginas interativas, uma voltada para os moradores e outra para a Defesa Civil, utilizando HTML, CSS e JavaScript.

Usamos Juiz de Fora (MG) como referência para o projeto.

## O que desenvolvemos?

**Dashboard do Morador**

- Exibição de um alerta de risco.
- Seleção entre dois abrigos.
- Troca do mapa conforme o abrigo escolhido.
- Atualização das informações na tela.

**Painel da Defesa Civil**

- Seleção da região monitorada.
- Alteração do nível de risco (baixo, moderado ou alto).
- Atualização das mensagens e cores dos alertas.
- Visualização de ocorrências.
- Opção de marcar ocorrências como verificadas ou desfazer a verificação.

## Tecnologias utilizadas

- HTML

## Como visualizar o projeto

Basta baixar o repositório e abrir o arquivo `index.html` no navegador.

Pelo menu superior, é possível navegar entre o Dashboard do Morador e o Painel da Defesa Civil.

## Importante

O ZELA ainda é um protótipo acadêmico. Os mapas, abrigos, alertas e ocorrências são demonstrativos e não representam informações reais de segurança.

As duas páginas funcionam de forma independente, sem comunicação automática entre elas.
